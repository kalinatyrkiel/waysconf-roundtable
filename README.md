# Scaling AI in design processes

Interactive slide deck for Kalina Tyrkiel-Szymańska’s WaysConf 2026 roundtable.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. Use arrow keys, Page Up/Down, Space, Home, End, the on-screen controls, or click the slide to navigate.
